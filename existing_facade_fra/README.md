# 기축 건축물 외벽 화재위험성 평가 방법(안) – 평가식과 5단계 절차

국내 기축(이미 지어진) 건축물을 형태와 관계없이 외벽 화재위험 측면에서 평가하는 절차입니다. 연구 방법론 제안용입니다.

- **어떤 형태든 하나의 식**: 외벽을 '구간'(같은 외벽 시스템 · 같은 노출의 수직 띠)으로 나눕니다. 필로티, 저층 상가 + 고층 주거, 측벽, 커튼월은 모두 구간의 조합으로 입력됩니다.
- **결과는 수치 + 등급**: 연간 노출 인원 R(명/년) → 1인당 위험 IR → 자택 화재 위험과의 비 r → 1–5등급. 대형 피해(M) · 급발(A) 표시와 우선순위(ΔR)를 함께 냅니다.
- **재료 시험이 들어가는 자리**: 시료(FT-IR · 콘 · TGA)와 시스템 시험(3 m 중공층 · 실대형 · FDS)은 평가식의 재료 인자(t₆₀₀ · p_B · A)를 보수값에서 측정값으로 바꿉니다. 이를 증거 수준 E0 → E3로 표시합니다.

모든 수치 · 그림은 `python ebfra.py`로 재현됩니다(→ [부록](#부록-재현-방법과-산출물)). 원자료(시험 엑셀)는 쓰지 않고, 앞선 분석의 결과값만 씁니다.

> **예시 입력 주의**
> - 실내 화재 빈도(λ_res)만 국내 통계에 근거합니다. 외부 화원 빈도 · 분기확률 · 시간 · s는 예시값이고, `inputs/parameters.csv`의 근거 열에 대체할 출처를 적었습니다.
> - 드라이비트 · 복합패널 · 샌드위치패널은 시스템 시험 자료가 없어 가연 경계값(t₆₀₀ 30 s)을 씁니다.
> - 예제 3동은 가상 건물입니다. 수치는 방법을 시연하는 값이며, 자료가 들어오면 같은 절차로 갱신합니다.

## 0. 핵심

1. **평가식은 하나입니다.** 덱 5쪽과 엑셀 `0_평가식` 시트에 있습니다(→ [1절](#1-평가식)).
   - R = Σ구간 (R1 + R2 + R3) [외벽 화재로 1년에 노출되는 재실자, 명/년]
   - R1 실내 화재의 창 분출, R2 외벽 하단 화원(필로티 차량 · 쓰레기 · 실외기 등), R3 아래 구간 최상층의 분출화염입니다.
   - 각 항 = 노출 빈도 × 위층 j개 층까지 번질 확률 × 그 층에서 아직 피난하지 못한 재실자.
2. **판정은 자택 화재 위험과 비교합니다.** r = (R ÷ 재실자) ÷ λ_res. 경계는 자택 화재 위험의 1 % · 10 % · 같은 수준 · 10배입니다.
   - 실내 화재가 주된 건물은 λ_res가 분자 · 분모에서 상쇄되어, 화재 빈도 통계가 다소 틀려도 등급이 안정적입니다.
3. **5단계 절차**: 0 선별(대장 · 사진 · 허가 시점) → 1 현장 → 2 시료 → 3 정밀(시스템 시험 · FDS) → 4 판정 · 대책.
   - 단계가 올라가도 식은 같고 재료 인자의 근거만 바뀝니다. 그래서 어느 단계에서 멈추든 같은 척도의 등급이 나옵니다.
4. **예제 3동(가상)**
   - A 필로티 다세대(드라이비트, 스프링클러 없음): **4등급(매우 높음)·M·A**. 위험의 58 %가 필로티 차량 화재입니다. 차단재만으로는 4등급 그대로이고, 차단재 + 확산방지구조 + 하단 보호를 함께 하면 2등급, 외장재 교체면 1등급입니다.
   - B 15층 아파트(중공층 PIR 준불연, 스프링클러): **2등급(보통)**. 증거 수준이 E0 → E3로 오르면 r 0.088 → 0.029, 3등급 이상일 확률이 25 % → 12 %로 줄어듭니다.
   - C 25층 주상복합(PE 심재 복합패널): **3등급(높음)·M·A**. 위험의 33 %가 저층 상가 분출이 고층 패널을 가열하는 경로(IE3)입니다. PE 심재 패널은 확산방지구조 · 차단재 효과를 인정하지 않으므로 교체만 등급을 낮춥니다(1등급).
   - 등급(1인당)은 A가, 우선순위(줄일 수 있는 노출 인원 ΔR)는 C가 가장 높습니다. 두 지표를 나눠 보고합니다.
5. **형태마다 먼저 모을 자료가 다릅니다**(민감도). 필로티는 외부 화원 빈도(λ_car · λ_adj), 중층 준불연은 실물 보정 s, 고층 가연은 스프링클러 · 최성기 확률(p_s · p_FO)이 등급을 좌우합니다.
6. **연구 과제 1순위**: 외벽 시스템 시험 DB(드라이비트 · 복합패널 · 샌드위치패널), 외부 화원 통계, 실물 보정 s, 기준 이력 확정, 과거 화재 사례로 등급 경계 검증.

## 1. 평가식

```
R  = Σ구간 z ( R1 + R2 + R3 )                                                  [명/년]

R1 = Σ발화층 i  f_i  Σj c(k) · [ p_e·a(j)·(b(j)·q_min + (1−b(j))·q_a) + (1 − p_e·a(j))·b(j)·q_b ]
R2 = Σ화원 s    F_s  Σj c(k) · p_e2 · a_s(j) · q_s(j)
R3 = f_하부          Σj c(k) · p_e2 · a(j) · [ b(j)·q_min + (1−b(j))·q_a − b(j)·q_b ]      (k = i + j)

f_i  = (n_u · λ_res  또는  면적 · λ_com) · (1 − p_s · 스프링클러(i층)) · p_FO · p_v · 창 계수
F_s  = λ_car · 주차면 · p_x(천장 가연 0.9 / 불연 0.5),  λ_adj · 개소 · p_x(0.3)
a(j) = (1 − p_cb)^j · S_FS(jτ) · [ p_B + (1 − p_B) · S_e(jτ) ],   τ = s · t₆₀₀ · h / 3 m   ← 재료 인자
b(j) = p_L^j · (1 − p_s)^(i < 층 ≤ i+j 의 스프링클러 층 수) · S_FS(j · τ_L)                   ← 창→창 도약
q(t) = P(RSET > t)   (+ p_st : 필로티 화재이고 1층 방화구획 없음)
c(k) = 확산 띠 세대 × 세대당 인원 × 실내 유입

IR = R ÷ 재실자,   r = IR ÷ λ_res
등급: 1 < 0.01 ≤ 2 < 0.1 ≤ 3 < 1 ≤ 4 < 10 ≤ 5,   M: C̄ = R ÷ F_ign ≥ 10명,   A: 급발 유형
R_ref = 같은 건물의 외벽을 모두 불연으로 바꿨을 때(b만 남음) → RR = R / R_ref, ΔR = R − R_ref
```

- S_FS: 외벽 화재 진압 전일 확률(로그정규). 층 바닥 높이가 고가사다리 도달 높이(50 m) 이하이면 중앙값 15분, 위면 45분.
- S_e: 분출화염이 남아 있을 확률(균일 분포). p_B: 버너 소화 뒤 외벽이 스스로 탈 확률.
- p_e: 단열재 · 중공층 노출 확률(개구부 차단재 0.9 → 0.3). p_e2: 하단 화원의 노출 확률.
- 가연재가 바깥 면이거나 패널 심재로 이어진 유형(PE 심재 복합패널 · 가연 샌드위치패널 · 미상 가연)은 p_cb · p_e 효과를 인정하지 않습니다(EFFECT와 같은 판단).

## 2. 구간 나누기

| 규칙 | 예 |
|---|---|
| 외벽 시스템이 바뀌는 높이 · 면에서 나눔 | C: 1–3층 석재 · 커튼월 / 4–25층 복합패널 |
| 창이 있는 면과 거의 없는 면은 나눔(창 계수 1 · 0.4 · 0) | B: 세대 창 면 / 측벽 |
| 수직으로 이어진 구간은 같은 '열' — 위층 도약 · 하부 분출(IE3)이 이어짐 | C1 → C2 |
| 하단 화원은 그 위 구간에 붙임 | A1: 필로티 주차 8면 |

건물 단위 입력: 층수 · 층고 · 사다리 도달 높이 · 스프링클러 설치 층 · 필로티(천장 마감, 1층 방화구획).

## 4. 재료 인자와 시료 시험

**2단계 시료 시험의 판정 순서**

1. FT-IR: 고분자(EPS · PIR/PUR · PF · PE 심재)와 난연제를 식별해 유형을 확정합니다.
2. 콘(KS F ISO 5660-1, 50 kW/m²): 준불연 기준 미달이면 가연 경계값(t₆₀₀ 30 s, p_B 0.5, A)을 씁니다.
3. TGA(공기, 5 °C/min): 준불연 · 탄화형(f₄₀₀,air ≥ 0.5)이면 t̂₆₀₀ = 247.5 + 422.97 / r_max,air, p̂_B = (f₄₀₀,air − 0.60) / 0.10(0.05–0.95)을 씁니다([integrated_model](../integrated_model/README.md), [multiscale_fra](../multiscale_fra/README.md)).
4. 용융형(f₄₀₀,air < 0.5)이면 유형 기본값에 급발 A를 붙입니다.

콘 게이트가 필요한 이유: 가연성 PIR(PUR)은 TGA로 812 s를 예측했지만 실측은 30 s였습니다.

증거 수준별 재료 불확실성(t₆₀₀의 로그 표준편차): E0 · E1 0.506(준불연 모집단), E2 0.166(TGA 예측식 잔차), E3 0.066(시험 2회).

## 7. 한계

- 빈도 · 분기확률 · 시간 · s는 예시값입니다(근거 표시). 실내 화재 빈도만 통계에 근거합니다.
- 시험 자료가 없는 외벽 시스템(드라이비트 · 복합패널 · 샌드위치패널)은 가연 경계값(30 s)입니다.
- 수직 확산만 다룹니다. 수평 확산 · 모서리 · 낙하물 · 연기의 실내 유입은 단순화했습니다.
- 구간 경계에서 외벽 경로는 끊긴다고 봅니다. 아래 구간 분출은 IE3로 반영합니다.
- 등급 경계(자택 화재 위험의 1 % · 10 % · 1배 · 10배)는 제안값입니다. 사례와 사회적 합의로 보정할 연구 대상입니다.
- 허가 시점 기준 중 2010 · 2015년 경계는 법령 원문으로 확정한 뒤 써야 합니다.
