# 샌드위치패널 외벽 화재확산방지 모듈 – 조인트 상세

기존 샌드위치패널 외벽에서 외부강판과 단열재를 띠 모양으로 걷어 낸 자리에 미네랄울 카세트를 넣는 안입니다.

- 기존 외부강판과 단열재는 상·하 두 줄에서 함께 잘라 냅니다.
- **상부 단열재에는 공간을 만들지 않습니다.** 겹침에 필요한 뒤 공간은 비어 있는 개구 안에서 만듭니다.
  - 상부 절단면 아래에 새 **캡레일**을 붙입니다. 캡레일 립이 기존 강판 면을 아래로 90 mm 이어 줍니다.
  - 카세트 **텅**이 그 립 뒤로 70 mm 들어갑니다.
- 하부는 스타터레일 앞날개와 카세트 스커트가 기존 강판 바깥을 차례로 덮습니다.
- 어느 조인트에서도 실리콘에 기대지 않습니다.

도면은 `python build.py`로 다시 만듭니다(표준 라이브러리만 사용). 출력은 `figures/*.svg`와 `index.html`입니다. 단위는 mm이고, 얇은 판 두께는 보이도록 과장했습니다.

| 조인트 | 처리 | 치수 |
|---|---|---|
| 상부 (D-02) | 캡레일 립이 기존 강판 면을 아래로 연장, 카세트 텅이 립 뒤로 겹침 | 립 90, 겹침 70, 들임 줄눈 15 |
| 하부 (D-03) | 레일 선반이 하부 절단면·강판 끝을 덮고, 앞날개와 스커트가 바깥에서 겹침 | 앞날개 50, 스커트 40 |
| 세로 (D-04) | 전면판 50 겹침 + 배수 채널, 미네랄울 50 단차 | 겹침 50 |

## D-02 상부 조인트 상세

![D-02 상부 조인트](figures/d02_top_joint.svg)

**빗물이 막히는 순서 (바깥 → 안)**

1. **강판 → 립**: 립 바깥면이 강판보다 0.5 mm 안쪽에 있어 턱이 없고, 물이 립으로 넘어갑니다.
2. **립 킥아웃 → 조글**: 립 하단에서 떨어진 물은 15 mm 아래 조글 경사에 받혀 전면판 바깥으로 흐릅니다.
3. **바람에 밀린 물**:
   - 들임 줄눈으로 들어온 물은 립과 텅 사이 3 mm 틈을 올라가야 합니다.
   - 이 틈은 위가 막히고 아래만 바깥과 통해 압력이 바깥과 같아집니다.
   - 그래서 텅 겹침 70 mm를 넘지 못합니다.
4. **맞댐부 스밈**: 강판 끝과 캡레일 사이로 스민 물은 립에서 10 mm 안쪽의 모세관 차단 홈에서 끊깁니다.

**치수 기준**

- 립 90 = 겹침 70 + 들어올림 12 + 여유 8. 들어올렸을 때 조글 상단이 립 하단보다 3 mm 아래에 머뭅니다.
- 립 위치는 강판 면보다 0–2 mm 안쪽이어야 합니다(튀어나오면 강판 끝 아래에 턱이 생김).
  - 캡레일 깊이는 실측 패널 두께 − 1.5 mm로 만듭니다.
  - 그러면 뒷다리를 내부강판에 붙이기만 해도 립 자리가 맞습니다.
- 캡레일은 3,000 mm마다 100 mm 겹치고, 겹침 위치는 카세트 세로 조인트와 엇갈리게 둡니다.
- 기존 강판 절단 끝은 징크리치(아연말) 도료로 방청합니다.

## D-03 하부 조인트 상세

![D-03 하부 조인트](figures/d03_bottom_joint.svg)

- 바깥부터 스커트 40 → 레일 앞날개 50 → 기존 강판 순으로 위가 아래를 덮습니다.
- 세로 조인트로 들어온 물은 다음 경로로 빠집니다.
  - 하부판 배수 노치를 지나 레일 선반에 떨어집니다.
  - 앞날개와 스커트 사이를 지나 레일 킥아웃으로 나갑니다.
- 하부판은 레일 리브 위에 얹히고, 아래로 접은 리브가 레일 리브 뒤에 8 mm 걸립니다.

## D-06 조인트가 걸리는 순서

![D-06 설치 동작](figures/d06_install.svg)

걸림 깊이는 상·하부 모두 8 mm이고, 들어올림은 12 mm입니다. 들어올리는 동안 압축 스트립은 20 → 8 mm로 눌렸다가 다시 20 mm로 돌아옵니다.

**시공 순서**

1. 상·하 절단선(간격 460)을 레이저로 먹매김합니다.
2. 외부강판과 단열재를 같은 선에서 함께 자릅니다. 깊이 스톱으로 내부강판을 보호하고, 불티 나는 공구는 쓰지 않습니다.
3. 단열재를 걷어 내고 강판 절단 끝을 방청합니다.
4. 상부 캡레일 상판을 상부 절단면에 밀어 붙이고 뒷다리를 피스 @150으로 고정합니다. 립이 강판 면보다 튀어나오지 않았는지 확인합니다.
5. 스타터레일 선반을 하부 절단면에 얹고 뒷다리를 피스 @300으로 고정합니다.
6. 카세트를 들고–밀고–내려 겁니다. 세로 조인트 겹침 방향은 한쪽으로 통일합니다.

## 조인트 부재 사양

| 조인트 | 부재 | 추천 사양 | 조인트에서 하는 일 |
|---|---|---|---|
| 상부 | 상부 캡레일 | 1.0t 도장강판(기존 패널 색), 길이 3,000, 깊이 = 패널 두께 − 1.5 | 단열재 절단면 덮개 · 물끊기 립 90 · 걸이 채널 · 모세관 차단 홈 |
| | 캡레일 피스 | 뒷다리 @150, 내부강판 | 캡레일과 카세트 상부 고정 |
| | 카세트 텅 | 전면판을 한 장으로 접은 연장부, 립 뒤 틈 3 | 립 뒤 70 겹침, 위에서 꺾여 상부판이 됨 |
| | 들임 줄눈 | 립 하단 ~ 조글 상단 15, 막지 않음 | 등압 개구, 들어올림 여유 |
| | 압축 불연 스트립 | 저밀도 미네랄울 또는 세라믹 블랭킷 30t → 20 | 상부판과 캡레일 사이 충전 |
| 하부 | 스타터레일 | 1.0t STS304, 길이 3,000, 리브 12 + 배수 노치 @150, 앞날개 50 + 킥아웃 | 하부 절단면·강판 끝 덮개, 기존 강판 바깥 50 겹침, 배수 |
| | 카세트 하부판 | 0.6t GI, 하향 리브 10 (걸림 8), 세로 조인트 위치 배수 노치 | 레일 리브 위에 얹힘, 이탈 방지 |
| | 스커트 | 전면판 하단, 레일 바깥 40 + 킥아웃 | 레일 앞날개를 바깥에서 덮음 |
| 세로 | 전면판 연장부 | 50 연장 + 조글(판 두께만큼) + 배수 채널 12×10 | 카세트끼리 50 겹침, 침입수 하부로 배수 |
| | 미네랄울 단차 | 앞뒤 절반씩 50 단차, t + 10 압축 | 이음부에도 불연재 연속 |

가정: 세로로 설치된 샌드위치패널(강판 0.5 mm, 도면 코어 두께 100 mm). 치수는 아이디어 단계의 추천값입니다.
