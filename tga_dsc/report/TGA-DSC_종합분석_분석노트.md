# TGA–DSC 종합분석 · 데이터 신뢰성 평가 — 분석 노트

- 대상: `TGA-DSC_종합분석_신뢰성평가.pptx` (16쪽, 와이드 16:9, 모든 쪽에 발표자 노트), 생성 스크립트 `build_deck.js`
- 자료: 단열재 6종 × N₂ · 공기(O) × 2회 = 원자료 24개 (`tga_dsc/data/N`, `data/O`, 저장소에는 없음)
- 요청 경과
  1. TGA–DSC 분석 데이터를 종합분석하고, 신뢰성이 없으면 추가 실험이 필요한지 확인 → 원자료 신뢰성 점검(`qa_reliability.py`)을 새로 만듦
  2. 보고서가 아니라 데이터 분석 파일(PPT 또는 docx)로 → 16쪽 PPT
  3. 슬라이드 노트 형식(입력 자료 → 산정 식 → 검산 → 해석 → 슬라이드 구성 → 발표자 노트 → 확인할 점 → 작업 기록)을 따름 → 이 문서

**결론**: 추가 실험은 **필요하지만 표적 보완**입니다. 필수 10회(블랭크 2 · EPS 가연성 공기 재측정 3 · 공기 3번째 반복 5)와 기록 확인 4건이면 됩니다. 전면 재시험은 필요 없습니다.

12개 조합(6종 × 2분위기)의 판정:

| 판정 | 조합 |
|---|---|
| 신뢰 3 | 공기 PF 내부용 · PF 외부용 · PIR(PUR) 가연성 |
| 조건부 3 | N₂ EPS 가연성 · 준불연, 공기 PIR(PUR) 준불연 |
| 종점 의존 5 | N₂ PIR(PUR) 2종 · PF 2종, 공기 EPS 준불연 |

## 2. 산정 식

### 2.1 TGA · DSC 지표

| 지표 | 식 | 의미 |
|---|---|---|
| 전환율 | α = (W_ref − W) / (W_ref − W_end) | W_ref: 승온 시작 평균, W_end: 790 °C 부근 평균 → 총 감소 중 진행된 몫 |
| DTG | r = dα/dT (Savitzky–Golay 10 °C) | r_max: 100–750 °C의 최대값(%/°C), T_peak: 그 온도 |
| 특성 온도 | T_α5 · T_α50 · T_α90 | α = 0.05 · 0.5 · 0.9인 온도. 초기 질량 기준 T5%와 다름 |
| 시작 온도 | T_onset = T_peak − [α(T_peak) − α(T_lo)] / r_max | 주 피크의 접선 외삽 |
| 고온 몫 | f₄₀₀ = 1 − α(400 °C) | 400 °C 이상에서 일어난 감소 비율 |
| 국소 열류 | h = H − SG₁₀₀(H) | 100 °C 창의 추세 제거(흡열 +). 사건의 온도와 부호만 씀 |

### 2.2 신뢰성 점검 (이 분석의 자체 기준, 표준 아님)

| 점검 | 산정 | 양호 | 보통 | 미흡 |
|---|---|---|---|---|
| 신호량 | 두 반복 중 작은 총 질량감소 | ≥ 1.0 mg | 0.5–1.0 | < 0.5 |
| 겉보기 증가 | 200 °C 이전 최대 증가 ÷ 총 감소 | ≤ 2 % | 2–5 % | > 5 % |
| 종점 잔여 | 790 °C 부근 감소속도 ÷ 피크 속도 | ≤ 5 % | 5–20 % | > 20 % |
| 온도 반복 | T_onset · T_peak · T_α50 반복 차이 중 최대 | ≤ 10 °C | 10–25 °C | > 25 °C |
| 속도 반복 | r_max 반복 차이 ÷ 평균 | ≤ 10 % | 10–20 % | > 20 % |
| 순위 분리도 S | 이웃 재료와의 r_max 차이 ÷ 반복 차이 | ≥ 3 | 1.5–3 | < 1.5 |
| DSC 재현 | 두 반복의 최대 사건(150–720 °C)이 온도 차 ≤ 10 °C, 같은 부호, 크기 ≥ 0.5 mW | 재현 | — | 비재현 |
| 종점 민감도 | α를 700 · 750 · 790 °C까지의 감소로 다시 정규화 | 지표 변화 = 분해 미완의 영향 | | |

### 2.3 종합 판정 (TGA 6개 점검만 사용, 위에서부터 적용)

1. 재측정: 신호량 · 겉보기 증가 · 속도 반복 중 하나라도 미흡 (측정 자체가 약함)
2. 종점 의존: 종점 잔여가 미흡 (정규화 지표가 종점에 좌우)
3. 조건부: 보통 항목이 하나라도 있음
4. 신뢰: 6개 모두 양호

## 3. 검산

### 3.1 요약표와 개별 시험

- `tga_summary.csv`의 평균과 개별 시험 평균의 차이는 r_max −0.02 ~ +0.01 %, f₄₀₀ −0.07 ~ +0.01 %입니다. 반올림 차이뿐입니다.

### 3.2 미분 방법: Savitzky–Golay vs 10 °C 중앙차분 (2회 평균)

| 조합 | r_max 차이 | T_peak 차이 |
|---|---|---|
| N₂ EPS 가연성 / 준불연 | −2.8 % / −1.0 % | −0.25 / −0.5 °C |
| N₂ PIR(PUR) 가연성 / 준불연 | −1.0 % / −2.3 % | −1.25 / +1.75 °C |
| N₂ PF 외부용 / 내부용 | −2.7 % / −0.7 % | +1.0 / **−12.0 °C** |
| 공기 EPS 가연성 / 준불연 | −3.2 % / −1.3 % | −1.5 / +1.25 °C |
| 공기 PIR(PUR) 가연성 / 준불연 | −0.7 % / −3.8 % | 0.0 / −2.25 °C |
| 공기 PF 외부용 / 내부용 | −1.9 % / −3.1 % | +1.25 / −1.0 °C |

- 중앙차분이 피크를 0.7–3.8 % 낮게 잡지만 재료 순서는 같습니다.
- T_peak는 2.3 °C 이내로 맞습니다. 예외는 PF 내부용 N₂(12 °C)로, 피크가 넓고 평탄합니다.

### 3.3 자기발열 (지표를 고쳐 다시 계산)

- 처음 계산(최대 지연 − 중앙값)은 승온 시작의 과도 응답(23–32 °C)을 잡아 8–11 °C가 나왔습니다. 자기발열이 아닙니다.
- 고친 계산은 150 °C 이상에서, 시료−프로그램 온도차의 10분 이동 중앙값 대비 최대 이탈을 봅니다.
  - 결과: 모두 0.22 °C 이하이고, 대부분 235 °C 부근에서 0.2 °C입니다. 모든 시험에서 같은 위치라 장비 요인으로 봅니다.
  - 예외는 PF 내부용 공기 0.37 · 0.96 °C(474 °C)로, DSC 발열 사건과 같은 온도입니다.

### 3.4 종점 민감도와 중공층 순위상관

공기 r_max(%/°C, 2회 평균):

| 재료 | 700 °C | 750 °C | 790 °C |
|---|---|---|---|
| PF 내부용 | **1.177** | 1.174 | 1.174 |
| EPS 준불연 | **1.237** | 1.155 | 1.014 |
| PIR(PUR) 가연성 | 0.747 | 0.748 | 0.750 |
| PIR(PUR) 준불연 | 0.601 | 0.588 | 0.575 |
| PF 외부용 | 0.413 | 0.408 | 0.406 |

- 700 °C로 끊으면 EPS 준불연이 PF 내부용을 앞질러 1 · 2위가 바뀝니다.
- EPS 준불연 공기의 T_α90은 503 → 584 → 758 °C로 움직입니다(종점 700 → 750 → 790 °C).

### 3.5 판정 기준의 민감도

- 모든 경계를 20 % 느슨하게 하면 바뀌는 판정이 없습니다.
- 20 % 엄격하게 하면 PIR(PUR) 준불연 공기가 조건부 → 재측정으로 바뀝니다(r_max 반복 차이 19.5 % > 16 %).
- '신뢰 3'은 어느 쪽에서도 유지됩니다.

### 3.6 DSC 부호와 재현 사건

- EPS 해중합(흡열 반응)이 N₂에서 +로 나오므로, 이 장비 출력은 흡열이 +입니다.
- 재현 사건은 2건입니다.
  - EPS 가연성 N₂: 399 · 398 °C, +0.8 · +1.2 mW (흡열)
  - PF 내부용 공기: 474.5 · 474 °C, −8.9 · −17.9 mW (발열)
- 나머지 10개 조합은 온도 차 > 10 °C이거나 크기 < 0.5 mW입니다.

## 4. 해석 — 왜 그렇게 되는가

### 4.1 잔류율 · J/g를 못 구하는 이유

- 질량 열에 절대 영점이 없습니다(시작 −1.22 ~ +2.70 mg, 23개가 음수로 끝남). 그래서 초기 질량과 잔류 질량을 알 수 없습니다.
- 블랭크가 없어서 부력과 열류 기준선을 뺄 수 없습니다. DSC 기준선이 100 → 700 °C에서 111–180 mW 움직이는데, 이는 가장 큰 사건(17.9 mW)의 6배 이상입니다.

### 4.2 EPS 가연성 공기만 재측정인 이유

- EPS는 밀도가 매우 낮아 도가니에 들어가는 질량이 작습니다. 공기 시험의 총 감소는 0.30 · 0.16 mg이고, N₂ 시험은 0.87 · 0.99 mg입니다.
- 부력에 의한 겉보기 증가(수십 µg)가 총 감소의 10 · 17 %가 되고, r_max 반복 차이가 33 %로 커집니다.
- 잡음 자체는 작습니다(등온 잡음 0.23–4.05 µg, 신호/잡음 ≥ 325). 문제는 영점과 부력입니다.

### 4.3 '종점 의존'의 뜻

- 790 °C에서도 감소속도가 피크의 23–102 %로 남아 있습니다. N₂의 PF 외부용 102 %, PF 내부용 65 %, PIR(PUR) 준불연 41 %, 가연성 25 %이고, 공기의 EPS 준불연이 40 %입니다.
- 총 감소량(정규화 상수)이 승온 종료 시점에 좌우되므로 r_max · T_α50 · T_α90 · f₄₀₀가 종점에 따라 바뀝니다.
- T_onset과 T_peak는 영향을 받지 않습니다. α와 r이 같은 상수로 나뉘어 접선 외삽 식에서 상수가 지워지고, 피크 위치도 상수와 무관하기 때문입니다.
  - 예외: 피크가 탐색 상한(750 °C)에 걸린 PF 외부용 N₂(745 °C)는 실제 피크가 아닙니다.

### 4.4 중공층 순위상관(ρ = 1.0)이 조건부인 이유

- 1 · 2위 쌍(PF 내부용 vs EPS 준불연)의 분리도가 1.8, PIR(PUR) 준불연 vs PF 외부용이 1.5입니다. 반복 차이와 크게 다르지 않습니다.
- EPS 준불연 공기는 종점 의존이라, 700 °C로 끊으면 순서가 바뀌어 ρ가 0.8이 됩니다.
- 점 4개에서 ρ = 1.0이 우연히 나올 확률은 1/24 ≈ 4 %입니다.

### 4.5 PIR(PUR) 가연성 예외는 자료 문제가 아님

- 공기 PIR(PUR) 가연성은 r_max 반복 차이 0.5 %, 분리도 47로 가장 안정된 자료입니다.
- 따라서 'r_max 0.75(중간)인데 중공층 30 s 전체 화염'이라는 예외는, TGA가 재지 못하는 요인(착화성 · 화염 전파 등)에서 온 것입니다.

### 4.6 PF 결과

- PF 내부용의 474 °C 발열 크기가 두 반복에서 2배 다릅니다(−8.9 · −17.9 mW). 총 질량감소(1.27 · 2.81 mg)와 같은 비율이라 시료량 차이로 설명됩니다.
- PF는 150 °C까지 총 감소의 2.0–5.1 %가 일어납니다(수분 · 휘발분). 그래서 T_α5(151–198 °C)를 분해 시작으로 읽으면 안 됩니다.
  - 공기 시료는 승온 전 30 °C 등온에서도 21–48 µg 줄었습니다. 수분 증발로 보입니다(추정).
- N₂에서 두 PF의 분리도는 0.9 · 0.95로 구분되지 않습니다. 측정 불량이 아니라 'N₂에서는 같은 열분해'라는 결과와 일치합니다.

## 8. 확인할 점

1. **O 분위기의 가스 종류**(공기 / 산소)가 원자료에 없습니다. 덱의 '공기(O)' 표기는 이 확인을 전제로 합니다.
2. **판정 기준은 이 분석의 자체 기준**입니다. 표준이 요구하는 반복성 기준이 따로 있으면 그에 맞춰 다시 판정해야 합니다(`qa_reliability.py` 맨 위의 상수).
3. 9쪽 곡선(통합 평가식 t₆₀₀ = 248 + 423 / r_max)은 **같은 준불연 4점으로 맞춘 식**이라 이 그림이 독립 검증은 아닙니다.
4. 추정으로 표시한 해석 세 가지는 측정으로 확인되지 않았습니다.
   - PF 공기 시료의 등온 중 감소는 수분 증발
   - EPS 준불연 공기의 고온 감소는 잔류물 산화
   - 235 °C 공통 온도 이탈은 장비 요인
5. 글꼴은 맑은 고딕(Malgun Gothic)입니다. 화면 확인은 LibreOffice(나눔고딕 대체)로 했으므로, PowerPoint에서 줄바꿈 위치가 약간 다를 수 있습니다. 제목은 두 줄로 직접 나눠 두었습니다.
6. 이전 중공층 보고서(Word/PDF, `cavity_fire_index/report/`)는 PIR(PUR) c/sc 추가 전의 판입니다. 이 덱과 함께 배포하려면 다시 만들어야 합니다.

### 검산 코드

```python
import pandas as pd
from itertools import permutations
from scipy.stats import spearmanr

v = pd.read_csv("results/qa_verdict.csv")
rp = pd.read_csv("results/qa_replicates.csv")
ep = pd.read_csv("results/qa_endpoint.csv")

# 1) 분리도 S = 이웃 재료와의 r_max 차이 / 반복 차이 (공기)
air = rp[rp.atmosphere == "oxidative (O)"].sort_values("mean_r_max_pct_C")
m, d = air.mean_r_max_pct_C.to_numpy(), air.d_r_max_pct_C.to_numpy()
gap = [min(abs(m[i] - m[j]) for j in (i - 1, i + 1) if 0 <= j < len(m)) for i in range(len(m))]
print(dict(zip(air.material, (pd.Series(gap) / d).round(2))))
# EPS_SC 1.79, PIR_SC 1.51, PF_in 9.76, PF_out 31.85, PIR_C 47.14 (CSV 반올림 때문에 덱 값과 ±0.3 차이)

# 2) 종점별 순위상관 (준불연 4종, t600 중앙값 s)
t600 = {"EPS_SC": 975.0, "PIR_SC": 1079.5, "PF_out": 1350.0, "PF_in": 514.0}
for e in (700, 750, 790):
    r = ep[(ep.atmosphere == "oxidative (O)") & (ep.endpoint_C == e)].groupby("material").r_max_pct_C.mean()
    print(e, round(spearmanr([r[k] for k in t600], [-t600[k] for k in t600]).statistic, 2))   # 0.8, 1.0, 1.0

# 3) 점 4개에서 ρ = 1.0이 우연히 나올 확률
print(1 / len(list(permutations(range(4)))))   # 0.0417

# 4) 종합 판정 수
print(v.overall.value_counts().to_dict())   # endpoint 5, conditional 3, reliable 3, remeasure 1
```
